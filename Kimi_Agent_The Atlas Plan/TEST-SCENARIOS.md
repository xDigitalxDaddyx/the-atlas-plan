# Run The Numbers — Realistic Test Scenarios

Four verified, realistic two-shop comparisons. Every number below was run through the
calculator's exact math and confirmed on the live page. Type the inputs in as-is; the
outputs are what the calculator shows.

**How to use:** Fill Job A and Job B exactly as listed. Where a field is marked "—",
leave it at 0/blank (it doesn't apply to that pay structure — the calculator hides it).

---

## ★ Scenario B — "The $5/hr Raise Lie" (the shareable one)

The offer *looks* better on paper ($37 vs $32) but pays far worse once slow weeks,
physical hours, tools, and commute are counted. This inversion is the screenshot moment.

| Field | Job A — Current job | Job B — The offer |
|---|---|---|
| Pay Structure | **Hourly** | **Flat Rate** |
| Rate | **$32.00** /hr | **$37.00** /flagged hr |
| Avg Flagged Hrs/Wk (normal) | — | 40 |
| Dead Weeks / Year (slider) | — | **14** |
| Flagged Hrs/Wk (dead weeks) | — | 18 |
| Physical Hrs at Shop / Week | **42** | **50** |
| Overtime toggle (1.5× over 40) | **ON** | — |
| Health Insurance ($/mo out of pocket) | 0 | $160 |
| 401k Match (% of gross) | 0 | 2 |
| Paid Days Off / Year | 5 | 5 |
| Tool Allowance ($/yr) | 0 | 0 |
| Annual Tool Costs ($/yr) | $2,500 | $9,500 |
| Commute: Round-Trip Miles / Day | 20 | 45 |

**Result:**
- Job A: gross **$70,176.00** → true **$64,106.00** → **$29.93/hr** effective (2,142 hrs/yr)
- Job B: gross **$64,084.00** → true **$45,913.18** → **$18.01/hr** effective (2,550 hrs/yr)
- Banner: **Job A wins — $29.93/hr true pay, beating Job B by $11.92/hr ($18,192.82/yr).**
- The $5/hr raise is actually an $11.92/hr pay cut.

## Notes

- **Effective wage** = true cost-adjusted income ÷ actual physical hours per year. That's
  the headline number — the "holy shit" metric.
- **True income** = gross − out-of-pocket insurance − tool costs + tool allowance −
  commute + 401k match value.
- All four scenarios verified against the calculator's math with a 14-check brute-force
  test (zeros, 52 dead weeks, 365 PTO, OT math, hybrid collapse, negative income) — all pass.
- The calculator currently starts with its own defaults; typing in any scenario above
  overwrites them for that session. Use Save/Load to keep one.
